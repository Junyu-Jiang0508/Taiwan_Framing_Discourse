## 背景
GPT 与 DeepSeek 两个模型在 L2-07（凝聚與願景動員 / Solidarity & Vision）这一标签上判断分歧最大，
是 Phase 2 "浮动能指"论证(Beat 3)复现失败的关键节点。本轮任务是判定这些分歧到底是模型错误，
还是该标签本身构念模糊导致的合理分歧。

## 任务
对 `coding_sheet_blind.csv` 中的 50 条句子，独立判断是否应标注 **L2-07**（True/False），
并写一句话理由。**请勿参考任何模型输出**——本表已刻意隐去 GPT/DeepSeek 的判断结果、阵营(camp)、
来源(source)等信息，避免锚定偏差。

建议两名编码者独立完成（`coder1_*` / `coder2_*` 两组列），全部编码完成后再对照两人的一致率，
以及与 `answer_key.csv` 中 GPT/DeepSeek 标签的吻合度。

## 判断依据（v11 码本，L2-07 原文定义）

**核心定义**：以動員語氣召喚團結、共同行動或國族未來方向。涵蓋顯性動員（呼籲、團結口號）與
隱性動員（政策意願、未來願景描繪、集體行動事件、批評隱含的方向召喚）——只要句子承載「方向性」
「未來性」或「行動性」即觸發。核心是「指向未來/指向行動」，不限於字面呼籲詞。

**五類觸發場景（符合任一即標 true）**：
1. 顯性團結呼籲：「一起」「讓我們」「站出來」「共同守護」「打勝仗」「必須贏」「加油」「為台灣」「目標是」「打造」等。
2. 政策意願表達（過往大量漏標區）：「政府應該/必須」「我們要做」「未來會」「應立刻檢討」「持續推動」「強化」「改善」等治理方向句式，不需顯性呼籲詞。
3. 未來願景描繪：「成為日不落國」「均衡發展」「壯大台灣」「打造智慧科技島」等——願景陳述本身即是動員。
4. 集體行動事件描述：遊行、抗議、集會、訴求列舉的報導本身承載動員語義。
5. 批評隱含的反向動員：「換我們做」「必須改變」「不能再容忍」之隱含期待，如「執政8年讓年輕人看不到希望」。

**排除情形**：
1. 純事實陳述、無方向性、無價值評估的新聞報導 → 不標。
2. 主軸為主權法理宣示且無未來行動指向 → 屬 L2-01，不標 L2-07。
3. 主軸為純成就陳述/數字展示且無未來行動指向 → 屬 L2-06，不標 L2-07。
4. 主軸為民主價值定義且無動員召喚 → 屬 L2-08，不標 L2-07。
5. 注意：句子若同時涉及主權/成就/價值，但**也**含方向性/未來性，仍應標 L2-07（可與其他標籤並存）。

**判定口訣**：句子是否承載「方向性、未來性或行動指向」？是 → L2-07。不要求顯性呼籲詞。

**正例**：
- 「強化台灣的經濟韌性，持續改善投資環境」→ 政策意願 → L2-07
- 「成為日不落國、產業升級、經濟轉型」→ 未來願景 → L2-07
- 「五一勞工大遊行4大訴求：勞工要加薪...」→ 集體行動事件 → L2-07
- 「執政近8年，讓年輕人看不到希望」→ 批評隱含期待 → L2-07
- 「希望未來能讓台灣不僅安全，也要有尊嚴」→ 願景動員 → L2-07

**反例**：
- 「侯友宜出席會議」（純事件報導，無方向）→ 不標
- 「民進黨在2020年大選獲13席」（事實陳述）→ 不標

## 文件说明
- `coding_sheet_blind.csv` — 交给编码者的表格：item_id + 上下文(context_prev/target_sentence/context_next) + 待填写的判断列。目标句为 `target_sentence`，前后句仅供理解语境，不单独打标签。
- `answer_key.csv` — **不要给编码者看**。含每条 item_id 对应的真实 doc_id/camp/genre/GPT 标签/DeepSeek 标签/分歧类型，供编码完成后核对一致率用。
- 抽样构成：50 条 = 40 条模型分歧句（3 阵营 × 2 种分歧方向，GPT标True/DS标False 与 GPT标False/DS标True 各约 20 条）+ 10 条模型一致句作为盲验校准锚点（5 条两者皆True + 5 条两者皆False，编码者不知道这些是"一致"样本）。

## 编码完成后的判读逻辑
1. 计算两名编码者之间的一致率/Cohen's κ —— 若很低，说明 L2-07 本身构念模糊，分歧不能全部归咎于某个模型，Beat 3 应降级为探索性发现。
2. 计算人工判断与 GPT / DeepSeek 各自的吻合率 —— 若人工明显偏向某一模型，则该模型的 L2-07 判断更可信，可考虑用它作为 Beat 3 的依据（但仍需在文中说明另一模型复现失败的原因）。
3. 检查校准锚点（10 条一致句）：编码者对这些"模型都同意"的句子的判断，应该也高度一致 —— 如果编码者在这些锚点上都出现分歧，那就是编码规则本身有问题，而非分歧句特别难判。
