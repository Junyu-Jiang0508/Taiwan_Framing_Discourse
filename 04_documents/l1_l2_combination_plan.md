# L1×L2 组合分析：任务划分与两人分工

---

## 1. 目标

A: L1×L2 的同句共标，测量议题层与国族层之间的纵向嵌套关系。国族能指出现在哪些议题域。

B: L2–L2 边在 L1 分层内重估，单位是三句窗，测的是国族层内部的横向共现关系。目标：同一条等价链在不同议题语境下是否被差异化激活。

C：加上党派+事件作为变量。测差的差，等 A、B 做完再决定。

---

## 2. 任务划分

边界：L2-01 主體性建構、L2-02 差異化認同、L2-03 國際合法性、L2-05 共同威脅設定。共同作用是划出"我们"与"他者"的界线。

凝聚：L2-04 集體敘事再造、L2-06 民族自豪感激發、L2-07 凝聚與願景動員、L2-08 民主價值強調。共同作用是填充"我们"的内容。

---

## 3. 共同规程

统计量：计数、行%、列%、lift、调整后标准化残差，区间估计用按 `doc_id` 重抽样的 cluster bootstrap，与 p2_03 同一单位。不建议使用卡方检验。

可以分阵营再出一份。

---

## 4. Layer B

### 边界

L2-01/02/03/05 之间的六条边，在每个选定 L1 层内、每个阵营内重估 NPMI。

需额外留意稀有对的不稳定性。这一侧的码基础频率差异很大，NPMI 在共现次数少时对增减极敏感，所以要报最低共现门槛、CI 宽度，并检查每条边是不是由少数几篇文档驱动。

### 凝聚

L2-04/06/07/08 之间的六条边。

留意 L2-06 与 L2-07 的语义邻接。验证阶段已经记录过这两个码存在系统性混淆，如果模型倾向对同一句同时打这两个标，这条边就会被同句共标机械推高。
