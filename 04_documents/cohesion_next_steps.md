 

# 凝聚簇发现的文献定位与下一步研究方向

配套 `cohesion_block_probe.md`（探针结果）。主规格：L1 = GPT，L2 = DeepSeek。

本文把探针的每一条发现——**显著的和不显著的都算**——放到对应文献里，判断它是
"已知现象的又一例证"还是"值得单独立论的新东西"，然后给出可执行的下一步。

文中标注：**[已验证]** = 本轮数据支持；**[待验证]** = 需要新分析；**[提议]** = 尚无数据的设计。

## 〇、两条前置检查的结果（写完初稿后补查，改变了优先级）

### 0.1 标注**带**上下文 —— §3.1 的负结果可以立论 [已验证]

`framing_batch_core.py:389-408` 的 `_build_user_text` 构造的用户消息是：

```
【前文（僅供語境參考，不標註）】{prev}
【本句（請標註）】{sentence}
【後文（僅供語境參考，不標註）】{next}
```

`prev` / `next` 在语料里填充率 **83.7% / 83.8%**（`merged_deduped.csv`），
两个 run 的 `final_results.csv` 都带这两列。

**所以标注不是上下文盲的**，§3.1"凝聚簇没有句间序列结构"不是标注设计抹掉的。
而且方向是保守的：模型看得到 ±1 句，如果它有"把上句的标签带过来"的倾向，只会**制造**
虚假的跨句相关——而我们一条也没测到（lag1/lag2 比值 0.96–1.11）。这让这个负结果更强。

方向 C 因此从"先查再说"升级为**可以直接立论**。

### 0.2 两套 L2 的**调用架构根本不同**，而这决定了共现结构 [已验证]

|          | GPT (`Run_20260407_221407`)       | DeepSeek (`Run_deepseek_l2binary`)    |
| -------- | --------------------------------- | ------------------------------------- |
| 调用方式 | **一次多标签调用**                | **8 次独立二元调用**                  |
| 输出列   | `L2_labels` + 单个 `L2_reasoning` | `L2-01`…`L2-08` 各带独立 `_reasoning` |
| 码间关系 | 8 码在**同一次生成里竞争**        | 各码**互不知情**                      |

对全部 28 对（含边界簇）重算 doc 内置换的同句超额：

| 指标                                  | DS         | GPT         |
| ------------------------------------- | ---------- | ----------- |
| 28 对的平均 ratio                     | **1.359**  | 1.118       |
| ratio < 1（低于零模型，即互斥）的对数 | **2 / 28** | **10 / 28** |

DS 的 ratio 高于 GPT 的有 **25 / 28** 对（Wilcoxon 配对检验 p = 4.8×10⁻⁵）。

（表已在过滤抓取残留后的语料上重算，生成代码现在是探针的第 11 节——初版这张表是
临场算的、没有脚本。过滤让结论**变强**：GPT 低于零模型的对数从 7/28 升到 **10/28**。
原因是残留行给两套标注都灌了虚假共现，把 GPT 的生成内竞争掩盖掉了一部分。）

而两者的**句长斜率几乎相同**（最短五分位→最长的标签数比值 2.20 vs 2.10）——
所以差别不在长度敏感性，而在**生成内竞争**。

**这意味着共现结构在很大程度上是由标注调用架构决定的，不只是由文本决定的。**

两个直接推论：

1. **GPT 的"互斥"是生成伪迹。** 它有 7/28 对低于零模型（04-06 = 0.862、04-07 = 0.889、
   02-06 = 0.861、05-06 = 0.791…）。单次多标签生成里，选中一个码会压制另一个码——
   这不是话语性质，是解码行为。我上一轮在 GPT 上看到的"04-06 互相排斥"就是这个。
2. **DS 的二元设计结构上无法执行码本的边界测试。** v10 码本的 `boundary_test` 字段
   全是**比较性**的（L2-02 的【vs L2-06】【vs L2-05】、L2-03 的【vs L2-06】、
   L2-04 的【vs L2-06】、L2-06 的【vs L2-02】【vs L2-04】）。逐码独立调用时，
   模型在判 L2-06 的那一次根本没被要求考虑 L2-02，所以"对比是分类性的还是等级性的？"
   这类判准无从执行。这是**码本与实现的结构性错配**。

两种设计都不对：一个制造虚假互斥，一个无法执行边界测试。这是一个可以单独写的方法论
发现，而且对整个 Phase 2 都成立，不限于凝聚簇。

（唯一反向的例外是 03-08：GPT 1.738 vs DS 0.961。这是 DS 的 L2-03 崩塌所致——
DS 下 L2-03 只剩 200 句、κ=.270，已在记忆中记为未解问题。）

### 0.3 抓取残留已在 p2_00 过滤，全部 Phase 2 估计重跑 [已验证，08-05]

§5 表里的第 1 项做完了。实现见 `02_src/phase2/utils/boilerplate.py`，
配置项 `corpus_filters.boilerplate_policy`（GPT / DS 两个 config 取同一值，
否则两套 L2 不在同一句子集上、对照失效）。

残留分两层：**drop**（整行就是残留——中央社文末标题串、TVBS 促销条、热线、授权声明，
每行 1.58 个 L2 码 vs 正文 0.99）与 **prefix**（真句子加抓取前缀——时间戳、
`透過 Google News`，标签负荷在正文水平上）。默认 `drop_residue` 只删 drop 层：
**1,314 行（5.86%），全部来自新闻**；prefix 层保留并打标，供方向 B1 当协变量。

**结论：全部既有结论存活，一处结构性变化。** 完整对比见
`03_outputs/01_results_labelings/09_boilerplate_filter_delta/`（GPT 与 DS 各一份）。

| 对象                | 结果                                                                 |
| ------------------- | -------------------------------------------------------------------- |
| 边 NPMI             | Pearson 0.997–0.998，平均 \|Δ\| 0.005–0.006，最大 0.024              |
| FDR 显著边集合       | DS 三阵营 Jaccard **1.000**；GPT 0.91–1.00                            |
| 凝聚簇六条边         | 全部 \|Δ\| ≤ 0.016，**无 FDR 翻转**                                   |
| QAP γ (p2_06)       | Δ ≤ 0.011，三对仍全部 p = 0.001                                       |
| 阵营对比 (p2_12)     | DS: DPP–KMT p 0.016 → **0.035**（仍显著）；GPT: 0.024 → 0.023         |
| Leiden 共识划分      | KMT ARI = 1.000；**DPP / TPP 变动（DS: 0.70 / 0.44）** ← 唯一不稳的一块 |
| §3.2 两条假边        | 控句长后从 1.016 / 1.008 落到 **0.997 / 0.986**，判定更干净            |
| §0.2 调用架构        | GPT 低于零模型的对数 7/28 → **10/28**，结论变强                        |

**Leiden 社群结构是唯一对过滤敏感的产物**：删掉 5.9% 的行就能让 DPP / TPP 的划分改变
（GPT 下 TPP 的 L2-08 从孤立点并入 02+04+05；DS 下 TPP 从 3 个社群变 4 个）。
这不是过滤的问题，是**社群检测在这个规模的网络上本身不稳**——8 个节点、边权连续，
Leiden 的划分边界本来就靠少数边的排序决定。含义：**论文不应把具体的社群成员名单当作
发现来陈述**，QAP 的"结构相似度"层面（对过滤完全免疫）才是可报的。

另外 `drop_residue` vs `drop_all` 的代价已量化：点估计 NPMI 相关 0.998、平均 |Δ| 0.005，
但 `drop_residue` 多 **1,707 个 n=3 窗口**。同样的答案，更多检验力。

顺带补了一档窗口：`robustness_ns` 现在是 `[1, 2, 5, document]`。以 n=3 为参照，
n=2 是**最贴近**的一档（GPT ρ=0.987 / Jaccard 0.884；DS 0.955 / 0.804），
比 n=5（0.945 / 0.847）更近，落差整个集中在 n=1→n=2 那一步。
这给方向 C 加了一条独立证据：**加宽窗口的边际信息在 n=2 就耗尽**——若真有跨句论证序列，
n=3、n=5 应当持续榨出新边，但没有。两种调用架构下形状一致。

## 一、本轮新增的两个发现（先说，因为它们改变了优先级）

### 1.1 L1→L2 的耦合是**跨阵营不变**的 [已验证]

分阵营重算 Layer A（7 个 L1 × 4 个凝聚码 = 28 格 lift 矩阵）：

| 阵营对  | Pearson | Spearman | 平均绝对差 |
| ------- | ------- | -------- | ---------- |
| DPP–TPP | +0.936  | +0.910   | 0.235      |
| KMT–TPP | +0.884  | +0.858   | 0.258      |
| DPP–KMT | +0.763  | +0.760   | 0.320      |

**给定议题域，三个阵营伸手去拿的认同资源是同一套。** 最锐利的两条耦合在三阵营几乎
一模一样：經濟×自豪感 lift = 2.41 / 3.04 / 3.27；經濟×民主價值 = 0.16 / 0.15 / 0.21；
衝突安全×民主價值 = 1.87 / 1.94 / 2.08。

这与 issue ownership 理论的朴素预期相反。Petrocik 的理论说政党会强调自己"拥有"的
议题；这里三阵营连**议题边际分布**都高度相似（L1 分布两两平均绝对差 0.012–0.029）。
但要注意一条解释性限制：语料是新闻+辩论，`camp` 是按提及/归属展开的，所以相似的议题
分布可能反映**新闻报道对三阵营用同一套故事类型**，而不是三阵营自己选择相同议题。
这个区分要靠体裁拆分来做（见 §4 方向 C）。

差异最大的三格（阵营间极差）：

| L1             | L2             | DPP      | KMT      | TPP      | 极差     |
| -------------- | -------------- | -------- | -------- | -------- | -------- |
| L1-05 社會正義 | L2-04 敘事     | 4.80     | 2.51     | 4.07     | 2.29     |
| **L1-01 經濟** | **L2-04 敘事** | **0.72** | **1.90** | **0.66** | **1.24** |
| L1-05 社會正義 | L2-08 民主     | 2.43     | 2.70     | 3.33     | 0.90     |

L1-05 那两格 n 只有 344，不稳。**唯一稳健的阵营差异是 KMT 独有的"經濟×集體敘事再造"
耦合（1.90 vs 0.72 / 0.66）**——只有国民党把历史叙事接到经济上。这与马英九时期经济
怀旧的常识判断吻合，但需要例句核实（`19_exemplars_0406.csv` + L1-01 过滤）。

另外 DPP–KMT 是三对里相关最低的（0.763），与 p2_12 已有的"DPP–KMT 阵营对比显著
（p=0.024）"方向一致。

**为什么重要**：项目已有的 Phase 2 结论是 p2_06 的 QAP 显示三阵营共享 L2–L2 网络结构
（γ≈0.88–0.95）。本发现把这个"共享"从 L2 内部推到了**L1→L2 的纵向嵌套**上：不只
认同码之间的关系是共享的，连"哪个议题该用哪种认同资源"也是共享的。这是一个更强的
命题，而且它是 plan 任务 A 的直接产出。

### 1.2 L1-06 被过度使用，且这是码本自己警告过的 [已验证]

L1-06 合法性與政府管理 占语料 **36.6%**（8,122 句），是最大的 L1 类。而 v9 码本对
L1-06 的定义里明确写着：

> 【萬物皆可涉及政策，切勿濫用此碼。L1-06不應常態性地作為主框架。】

它在辩论（36.9%）与新闻（36.5%）里比例几乎相同，所以不是体裁效应，是**码本执行问题**。
L1-07 情感/情緒（20.6%）按定义是"文本的組織原則為表達或喚起情緒狀態…而非建構論證"
的残余类，在新闻里 21.0%、辩论里 12.4%——这一个是体裁驱动的。

两者合计 **57.2%** 的语料。这直接影响 §2.3 那条负结果的读法。

## 二、显著发现：文献定位与下一步

### 2.1 L2-08 是枢纽，L2-07 只经它接入

**发现**：四条留存边里 L2-08（民主價值）占三条；L2-07（動員）与 L2-06（自豪感）、
L2-04（歷史敘事）的直接边在控制句长后消失。动员不直接从成就或历史里长出来。

**文献定位**：这正好落在 Snow & Benford 的 **collective action frame** 三重任务上——
diagnostic（问题诊断）/ prognostic（方案）/ **motivational（动员）**。Benford & Snow
反复强调 motivational framing 需要独立的"vocabularies of motive"，不能由前两者自动推出。
本发现是这个理论命题在语料层面的**直接量化证据**，而且证据形式是新的：不是问卷或
质性阅读，是共现结构中的**结构洞**。

Gamson 的 injustice–agency–identity 三元组给出另一个读法：L2-08 提供 identity 成分，
L2-07 提供 agency 成分，两者必须联结才构成完整的行动框架。

**下一步 [待验证]**：

- 把边界簇的 L2-05 共同威脅設定当作 diagnostic 项接进来，检验完整路径
  `L2-05(诊断) → L2-08(价值/身份) → L2-07(动员)`，看 05-08 与 08-07 是否都强于 05-07。
  这是一个可证伪的中介结构假设，数据已有。
- 若成立，凝聚簇/边界簇的二分就要重写：不是"划界 vs 填充"，而是
  **诊断 → 正当化 → 动员**的功能链，横跨两个块。这会直接改 plan §2 的任务划分。

### 2.2 經濟↔自豪感 vs 衝突安全↔民主價值 的互斥

**发现**：L2-06 在 L1-01 經濟 lift 2.88 / ASR 26.7（全表最强）；L2-08 在經濟
lift 0.18 / ASR −8.8。反向：L2-08 在 L1-03 衝突與安全 lift 1.98 / ASR 19.6。
去 boilerplate 后 lift 变化 ≤0.05，稳。

**文献定位**：最贴的框架是 Scharpf 的 **input / output legitimacy**：

| 本项目码                             | Scharpf               | 内容                           |
| ------------------------------------ | --------------------- | ------------------------------ |
| L2-06 民族自豪感（成就、数据、排名） | **output legitimacy** | 绩效正当性——"因为我们做得好"   |
| L2-08 民主價值（制度、程序、法治）   | **input legitimacy**  | 程序正当性——"因为我们这样决定" |

于是这条发现可以重述为：**经济议题几乎完全由绩效正当性承载，安全议题几乎完全由程序
正当性承载，两者在议题层上互不越界。** 这比"lift 高低"有意思得多，而且是可以直接
写进论文的理论主张。

台湾语境让这条更有分量：半导体/"矽盾"叙事是绩效正当性的极端形态（2023 年半导体
占出口近 30%、GDP 15–20%），而"民主前线"叙事是程序正当性的极端形态。本发现说明
这两套叙事在话语层面是**分工而非融合**的——这与"民主+晶片"常被合并宣传的印象相反。

Billig 的 banal nationalism 提供第三条线索：经济数字作为日常"flagging"，不需要显性
国族语言就在再生产国族标准——这正是 v10 码本给 L2-06 加的"负面对比自豪"条款所依据的
机制。

**下一步 [待验证]**：

- **[优先]** 检验绩效/程序正当性的配置是否随**执政/在野**而变，而不是随阵营而变。
  DPP 执政八年，理论预期它更依赖 output；KMT/TPP 在野，应更依赖 input 或"负面对比
  自豪"。§1.1 显示耦合矩阵跨阵营不变，所以若要找差异，应该去**边际强度**和
  **时间轨迹**里找，不是去耦合结构里找。
- 时间维度：`time_bucket` 已有五档。绩效正当性在选前（政绩宣传）与选后应有不同轨迹。
- 质性配合：抽 L1-01 ∩ L2-06 的高 lift 句子，看是否集中在半导体/GDP/排名这类"矽盾"
  词汇上（`04_layerA_l1_x_l2.csv` 定位 + 现有例句导出脚本）。

### 2.3 两个最大议题域全面抑制凝聚簇 —— 需要拆成两个不同的解释

**发现**：L1-06（36.6%）与 L1-07（20.6%）四个凝聚码 lift 全部显著小于 1。合计 57.2%
的语料是国族建构话语的荒漠。

**文献定位（两条竞争解释，必须分开）**：

1. **实质解释**：Aalberg / Strömbäck / de Vreese 的 **strategy & game framing** 文献
   反复发现，选战报道被策略、民调、输赢、候选人形象占据，挤压实质议题框架
   （Cappella & Jamieson 的"犬儒螺旋"是其后果侧）。L1-07 情感/情緒 在新闻里 21.0%、
   辩论里 12.4% 的体裁落差**支持**这条解释：这是新闻报道体制的产物。
2. **测量解释**：L1-06 是码本明确警告不该常态化使用的码，却成了模态类，且在两个体裁
   里比例相同（36.9% / 36.5%）——这更像 L1 码本执行问题，不是现象。

**下一步 [待验证]**：

- **先做测量诊断，再谈实质。** 抽 300 句 L1-06 做人工复核，估计"该判 L1-06"的比例。
  若真阳性率低，L1 层需要重标或重划，本条发现的实质版本才成立。
- 若 L1-06 确实被滥用，一个低成本补救是把它拆成"政策机制"与"政治过程/策略"两个子类
  ——后者正好对应 strategy frame 文献的操作化，可以直接引用现成量表。
- L1-07 那一半可以先按实质解释写，因为体裁落差支持它。

### 2.4 四条留存边的内部结构

**发现**：04-08 (.219)、07-08 (.159)、04-06 (.154) 稳，06-08 (.122) 弱。

**文献定位**：DHA 的建构策略分工（perpetuation / justification / positive
self-presentation / unification）预期的是**有选择性**的耦合，本结果证实了这一点。
但 DHA 从没说清楚哪些子策略会捆在一起——本项目给出的是一个**经验性的策略语法**。

Matthes & Kohring 的 frame elements 方法在这里是最直接的方法论亲缘：他们主张不要直接
编码"框架"，而是编码框架的**元素**，再用聚类归纳出框架包。本项目的 L1×L2 结构正是
"议题元素 × 认同元素"，四条留存边就是候选的元素捆绑。

**下一步 [提议]**：

- 用 Matthes–Kohring 路线做一次**归纳式**框架识别：以句子（或段落）为单位，把
  8 个 L2 + 7 个 L1 当作元素向量做聚类，看归纳出的框架包是否复现"04-08 / 07-08 / 04-06"
  这三条捆绑。若复现，就从"边"升级到"框架包"，表述力强得多。
- 注意 Matthes & Kohring 用的单位是**段落**而非句子——这与本项目 §2.1 的负结果
  （见下）直接相关，见 §4 方向 C。

## 三、不显著与否定发现：这些同样要写

> 文献共识：null finding 不是"没结果"。在设计良好的检验里，缺失关联能挑战既有预设、
> 提高元分析中效应量的精度、并提示存在调节变量。本项目的三条负结果都属于这一类。

### 3.1 凝聚簇没有句间序列结构 —— 最有理论价值的负结果

**发现**：文档内逐标签置换零模型下，六条边在 lag1/lag2 的观测/零模型比全在 0.96–1.11，
方向偏斜 ±0.06 内。全部可测的局部结构都在同一个句子里。

**为什么这是个真命题而不是"没测到"**：DHA 把策略定在**文本片段**层面；
Matthes & Kohring 用**段落**做单位；Monroe's motivated sequence 这类修辞学模型明确预设
"注意→需求→满足→visualize→行动"的**顺序**。本发现说这些预设在本语料上不成立：
共articulation 的实际尺度是**句子**。

**竞争解释必须排除**：

- (a) 真实现象：政治传播语料本来就不是连贯论证，是命题拼贴。
- (b) 语料伪迹：新闻语料 87.8% 是正文但含 12.2% 抓取残留，且新闻本身高度模块化
  （导语+引语+背景），天然缺乏论证序列。
- (c) 标注伪迹：LLM 逐句独立标注，看不到上下文，所以**结构上不可能**产生跨句依赖。
  **这条最致命**——如果标注是逐句无上下文的，跨句序列结构就是被标注设计抹掉的，
  不是语料里没有。

**下一步 [待验证，最高优先]**：

- **先查标注设计**：`02_src/utils/framing_batch_core.py` 与 prompt 里，L2 标注是逐句
  独立还是带上下文窗口？若逐句独立，则 §3.1 的负结果**没有实质解释力**，只能作为
  方法论限制写出来。这是一个一小时能查清的问题，但决定了这条发现能不能立论。
- 若标注确实带上下文，则做体裁拆分：辩论（连续论证）vs 新闻（拼贴）应有不同序列结构。
  但辩论只有 966 句，需要先评估检验力。

### 3.2 06-07 与 04-07 是句长假象

**发现**：控制句长四分位后同句超额降到 1.016 (z=1.0) 与 1.008 (z=0.3)。06+07 双标句
平均 113 字，比 06 单标长 33%，且在两套触发词上都高于各自单标组。

**文献定位**：LLM 的 **length / verbosity bias** 已有明确文献——模型倾向给更长的文本
更多、更"丰富"的标签，且弱模型受影响更大。在多标签设定下，这直接表现为"长句吸引
多标签"，从而机械抬高任意两码的同句共现。

更一般地，这属于 **LLM 标注误差传导** 问题：measurement error from LLM annotation is
non-classical——它不只是衰减关系，还能扭曲、放大甚至反转下游结论；即使代理标签准确率
达 80–90%，直接用于下游统计分析仍会产生实质偏误和无效置信区间。

**下一步 [提议，方法上最必要]**：见 §4 方向 B——换成带协变量的 Ising 回归。

### 3.3 GPT 的 L2-07 效度低于随机，且不能当稳健性检验

**发现**：人工金标准下 GPT κ = −0.20（precision 0.20，50 题 20 个假阳性），DS κ = 0.44。
两套标注给出的六边排序 Spearman 在 TPP 内是 **−0.31**。

**文献定位**：这是 LLM-as-annotator 文献的教科书案例。核心结论是：代理标签的误差是
非经典的，且**不能靠"两个模型互相验证"来诊断**——拿一个已知劣于随机的标注去检验
另一个只会得到无信息的分歧。正确做法是用少量金标准做设计层面的修正。

**下一步 [提议]**：见 §4 方向 B——DSL。

### 3.4 "少数文档驱动"没有发生

**发现**：六条边的有效文档数 174–472，单文档最高占比 2.6%，逐文档 jackknife
ΔNPMI ≤ 0.012。plan §4 给凝聚侧留的这条注意事项可以撤掉。

**文献定位**：这条对应共现网络的 **backbone extraction** 文献。Neal 等人系统比较了
FDSM / SDSM / FFM / FRM / FCM 等零模型，核心问题正是"观测到的共现次数是否显著、
因而是否该保留这条边"。**本项目用的逐标签文档内置换零模型实质上是 FDSM 的一个变体
（固定每文档每码的度）。**

**下一步 [提议]**：把置换零模型改写成标准的 SDSM/FDSM 表述并引用该文献。这有两个好处：
(1) 从"我们自己设计的检验"升级为有文献支撑的标准方法；(2) `backbone` R 包提供现成的
显著性检验与多重比较处理，省掉自己造轮子。SDSM 还支持边约束（SDSM-EC），可以把
"boilerplate 行不参与成边"这类约束显式写进零模型。

## 四、三个可执行的研究方向（按优先级）

### 方向 A：把 Layer A 写成"两种正当性资源的议题分工"—— 现在就能写

**论点**：绩效正当性（L2-06）与程序正当性（L2-08）在议题域上严格分工，且这个分工
**跨阵营不变**。国族认同的动员不是一个统一的资源池，而是一套按议题域索引的
资源调用规则。

**已有材料**：`04_layerA_l1_x_l2.csv`（含分阵营）、`05_l1_block_balance.csv`。
统计量已按 plan §3 规格产出（计数/行%/列%/lift+cluster bootstrap CI/ASR，未用卡方）。

**还需要做的**：

1. 阵营不变性的正式检验——目前只有 lift 矩阵的相关系数（0.76–0.94）。应该做成
   与 p2_06 同规格的 QAP 或阵营置换检验，才能和 Phase 2 已有结论并排放。
2. 执政/在野 × 时间轨迹的分解（见 §2.2）。
3. KMT 独有的"經濟×集體敘事"耦合的例句核实。

**风险**：L1-06 的过度使用（§1.2）会污染 L1-06 那一行。但主线结论落在 L1-01 與 L1-03
上，这两个域的 boilerplate 率最低（9.4% / 12.6%）且去 boilerplate 后 lift 变化 ≤0.05，
所以主线不受影响。

### 方向 B：换估计量 —— 带协变量的 Ising 回归 + DSL

这一条同时解决 §3.2 与 §3.3，是方法上最必要的一步。

**B1. 用 Ising 回归替代 NPMI。** Ising regression 为二值响应向量给出显式联合分布，
主效应建模为协变量的函数，**成对交互系数直接对应"给定其余变量下的条件依赖"**。
把句长、`is_boilerplate`、L1、camp、genre 放进主效应，成对交互项就是"净边"——
句长混杂被吸收进主效应，不再污染边。

这比现在的做法好在三点：

- 从"逐层收紧置换零模型"（ad hoc）变成一个统一模型，"四真两假"成为系数的直接读数；
- 条件依赖 ≠ 边际共现，正是本项目想要的"控制其他码之后 A 与 B 是否仍相关"；
- 有现成实现与稀疏化方法（eLasso 系列，网络心理测量学的标准工具）。

**B2. 用 DSL 处理标注误差。** Egami / Hinck / Stewart / Wei 的 design-based supervised
learning：把少量金标准与大量 LLM 标签结合，双稳健估计，**即使代理标签任意有偏也能
给出有效推断**，关键是要控制"哪些文档被抽去做金标准标注"的概率。

**本项目已经具备做 DSL 的条件**：`07_l207_arbitration/gold_standard_l207.csv` 有 50 条
L2-07 的人工金标准。缺的是（a）抽样必须是设计已知的随机抽样——需要核对这 50 条当初
是怎么抽的；（b）其余码也需要金标准，尤其 **L2-06**（重标下规模腰斩、κ=.391，是
04-06 与 06-08 两条边的共同端点）。

**建议的最小可行方案**：按已知概率抽 300–400 句做多码人工标注（覆盖 04/06/07/08），
用 DSL 重估 Layer A 的 lift 与 Layer B 的边。这批标注同时能回答 §2.3 的 L1-06 复核。

### 方向 C：共articulation 的尺度问题 —— 前置检查已通过，可以立论

§0.1 已确认标注带 ±1 句上下文（填充率 83.7%）且明确指示"僅供語境參考，不標註"。
所以负结果不是上下文盲造成的，而且偏向保守。

**可立论的命题**：_政治传播语料中，认同策略共articulation 的尺度是句子，不是话语片段。_
这直接挑战 DHA 把策略定在文本片段层面的预设、Matthes–Kohring 用段落做单位的选择、
以及 Monroe's motivated sequence 这类预设修辞顺序的模型。

**还需要做的**：

- 体裁拆分做调节变量检验（辩论 = 连续论证 vs 新闻 = 命题拼贴）。**但辩论只有 966 句
  （新闻 21,249 句），必须先算检验力**——现有辩论量很可能不足以支撑分体裁的边估计。
  若不足，这条只能作为定性讨论，或者需要补辩论语料。
- 与 §0.2 联动：既然共现结构受调用架构影响，"尺度是句子"这个结论也要在两种架构下
  各验一次才稳。目前 DS（独立二元）与 GPT（联合多标签）在 lag1/lag2 上**都**接近零模型
  （0.96–1.11 与 0.98–1.11），这一点是跨架构一致的——这是这条负结果最强的支撑。

### 方向 D（新增，来自 §0.2）：标注调用架构作为设计变量

这是本轮最意外的发现，而且它的适用范围超出凝聚簇，覆盖整个 Phase 2。

**问题**：一次多标签调用制造虚假互斥（GPT 7/28 对低于零模型）；逐码独立二元调用
无法执行码本的比较性边界测试（v10 的 `boundary_test` 全是【vs L2-XX】形式）。
两种设计都会系统性地改变共现结构，而共现结构正是本项目的因变量。

**下一步 [提议]**：

1. **最小实验**：在同一批 300–500 句上跑三种架构——(a) 联合多标签、(b) 逐码独立二元、
   (c) 逐码二元但 prompt 内嵌该码的全部 `boundary_test` 与对照码定义。比较三者的
   28 对同句共现矩阵与对人工金标准的 κ。这能同时回答"哪种架构更准"和"架构改变多少
   共现结构"。
2. 若 (c) 明显优于 (b)，则应重跑 L2 标注——这是把码本的边界测试真正执行起来的唯一办法。
3. 无论结果如何，**论文里必须把调用架构作为显式的设计说明写出来**，并报告
   §0.2 那张 28 对的对比表作为敏感性分析。据我所检索的文献，LLM 标注的
   length/verbosity bias 与误差传导都有讨论，但"调用架构如何塑造多标签共现结构"
   这一点没有现成的处理——这是一个可以独立成文的方法论贡献。
